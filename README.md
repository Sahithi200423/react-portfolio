# Sahithi Chukka — React Developer Portfolio

A futuristic, high-performance developer portfolio website built from scratch with **React 19**, **Vite**, **Three.js WebGL**, and **Supabase**.

## Tech Stack
- **Framework:** React 19 + Vite
- **Styling:** Modern CSS with custom design tokens, Midnight Navy & Cyan glassmorphism
- **3D Graphics:** Three.js interactive particle constellation
- **Icons:** Lucide React
- **Backend & Database:** Supabase (Row Level Security for contact messages)
- **Deployment:** Vercel

## Local Development
```bash
npm install
npm run dev
```

## Production Build
```bash
npm run build
```
